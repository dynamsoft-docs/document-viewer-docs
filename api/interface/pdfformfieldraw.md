# PdfFormFieldRaw

The raw data type of a form field. It is returned by [`FormManager.getFieldRaws()`]({{ site.api }}class/formmanager.html#getfieldraws) and [`FormManager.getFieldRawByUid()`]({{ site.api }}class/formmanager.html#getfieldrawbyuid). It is a serializable raw data snapshot; the properties may vary depending on the PDF type, the parser version, or extended fields.

## Syntax

```typescript
interface PdfFormFieldRaw {
  uid?: string;
  name?: string;
  type?: string;
  modified?: boolean;
  value?: PdfFieldValue;
  defaultValue?: PdfFieldValue;
  readonly?: boolean;
  visible?: boolean;
  required?: boolean;
  noExport?: boolean;
  isUnison?: boolean;
  topIndex?: number;
  isMultiSelectListBox?: boolean;
  defaultAppearance?: string;
  defaultAppearanceData?: Record<string, unknown>;
  options?: {
    exportValue: string;
    displayValue: string;
    selected?: boolean;
  }[];
  additionalAction?: Record<string, PdfFormActionRaw>;
  widgets?: PdfFormWidgetRaw[];
  kids?: PdfFormFieldRaw[];
  isSignatureApplied?: boolean;
  [key: string]: unknown;
}
```

## Attributes

### uid

The globally unique uid of the field, generated by DDV when parsing the form. It is unique within the current DDV runtime.

### name

The name of the field.

### type

The type of the field.

### modified

Whether the field has been modified.

### value

The current value of the field. The type is [`PdfFieldValue`]({{ site.api }}enumeration-type/pdffieldvalue.html).

### defaultValue

The default value of the field. The type is [`PdfFieldValue`]({{ site.api }}enumeration-type/pdffieldvalue.html).

### readonly

Whether the field is read-only for direct user editing.

### visible

Whether the field and its associated controls are displayed.

### required

Whether the field is required to have a valid value.

### noExport

Whether the field is excluded when the form is exported.

### isUnison

Whether the field is a unison field.

### topIndex

The index of the first option displayed in the current viewport of a list box.

### isMultiSelectListBox

Whether the field is a multi-select list box.

### defaultAppearance

The default appearance string of the field.

### defaultAppearanceData

The parsed default appearance data of the field.

### options

The array of options of the field (for list boxes, combo boxes, check boxes or radio buttons). Each option contains the export value, the display value and an optional `selected` flag.

### additionalAction

The additional actions of the field. The keys are the action names and the values are [`PdfFormActionRaw`]({{ site.api }}interface/pdfformactionraw.html) objects.

### widgets

The array of the widget raw data of the field. Each item is a [`PdfFormWidgetRaw`]({{ site.api }}interface/pdfformwidgetraw.html) object.

### kids

The array of the child fields of the field.

### isSignatureApplied

Whether a signature has been applied to the field.

## Remark

- All the properties are optional; callers must be able to handle missing properties caused by different field types.
- The concrete content of `options`, `widgets`, `kids` and `additionalAction` is determined by the field type and the PDF document.
- `[key: string]: unknown` means the parser can keep other PDF or parser extension properties. Business code must perform its own type checks when reading properties that are not agreed upon.
