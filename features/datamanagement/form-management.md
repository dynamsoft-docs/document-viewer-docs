# Form Management

DDV provides PDF form field management and form-filling functionality through the [`FormManager`]({{ site.api }}class/formmanager.html) class. With `DDV.formManager`, you can read the data of the form fields in a document and update their runtime properties (value, visibility, read-only, required, etc.). Combined with the form-related methods and events of [`EditViewer`]({{ site.api }}class/editviewer.html), you can also locate the rendered form widgets in the viewer and respond to widget clicks.

The form functionality is provided by the standalone form [plugin](/features/plugins-and-on-demand-loading.md), which must be installed after the annotation plugin.

## Get the raw data of form fields

### Get all the fields in a document

Use [`getFields()`]({{ site.api }}class/formmanager.html#getfields) to get the data of all the form fields in the specified document.

```typescript
const docUid = editViewer.currentDocument.uid;
const fields = Dynamsoft.DDV.formManager.getFields(docUid);

fields.forEach(field => {
  console.log(field.uid, field.type, field.value);
});
```

### Get a field by its uid

Each field has a globally unique field uid, which is generated by DDV when the form is parsed. Use [`getFieldByUid()`]({{ site.api }}class/formmanager.html#getfieldbyuid) to get a single field.

```typescript
const field = Dynamsoft.DDV.formManager.getFieldByUid(fieldUid);
if (field) {
  console.log("Current field value:", field.value);
}
```

The returned object is a [`FormField`]({{ site.api }}interface/formfield.html). All the properties except `alternateName` are optional and may vary depending on the field type, so you must handle missing properties in your business code. For example, a text field usually has a `string` value while a check box usually has a `boolean` value.

## Update the runtime properties of a field

Use [`setFieldProps()`]({{ site.api }}class/formmanager.html#setfieldprops) to update the runtime properties of a field. Only the properties passed in are updated; the others stay unchanged. The associated form controls refresh automatically.

For example, fill in a text field and mark it as read-only:

```typescript
Dynamsoft.DDV.formManager.setFieldProps(fieldUid, {
  value: "Filled",
  readonly: true,
});
```

Check a check box:

```typescript
Dynamsoft.DDV.formManager.setFieldProps(fieldUid, {
  value: true,
});
```

Hide a field:

```typescript
Dynamsoft.DDV.formManager.setFieldProps(fieldUid, {
  visible: false,
});
```

The properties you can update are defined in [`EditableFieldProps`]({{ site.api }}interface/editablefieldprops.html), including `value`, `alternateName`, `readonly`, `required`, `visible` and `removeUponSaving`. When `removeUponSaving` is set to `true`, the field is removed when the PDF is saved, which is useful when a signature is applied over the field.

## Locate the rendered form widgets in the viewer

### Get the widget DOM elements

Use [`getFieldElements()`]({{ site.api }}class/editviewer.html#getfieldelements) to get the widget DOM elements of a field that are already rendered in the current `EditViewer`. Each returned [`FieldElement`]({{ site.api }}interface/fieldelement.html) contains the `container` and the `content` DOM elements of a widget. The result only contains the controls already rendered in the current viewer; the controls in virtual-rendered, invisible, or destroyed pages are not included.

```typescript
const elements = editViewer.getFieldElements(fieldUid);
elements.forEach(el => el.content.classList.add("is-active"));
```

### Navigate to a field

Use [`goToField()`]({{ site.api }}class/editviewer.html#gotofield) to navigate to the page containing the field and scroll the first rendered control of the field to the center of the viewport.

```typescript
const located = editViewer.goToField(fieldUid);
if (!located) {
  console.warn("The field does not exist or is not rendered yet.");
}
```

## Respond to widget clicks

Use the `widgetClicked` event of `EditViewer` to detect clicks on the rendered form widgets. The listener receives an [`IWidgetClickedEvent`]({{ site.api }}interface/iwidgetclickedevent.html) object which contains the field uid, the widget uid, the [`FieldElement`]({{ site.api }}interface/fieldelement.html) of the clicked widget and the [`WidgetStyle`]({{ site.api }}interface/widgetstyle.html) of the widget.

```typescript
const listener = (event) => {
  console.log("A widget is clicked", event.fieldUid, event.widgetUid);
  const field = Dynamsoft.DDV.formManager.getFieldByUid(event.fieldUid);
};

editViewer.on("widgetClicked", listener);

// Unbind the listener when it is no longer needed.
editViewer.off("widgetClicked", listener);
```

The `style` attribute describes the layout of the widget (position and size). It is not a `CSSStyleDeclaration`; to modify the widget style, use the DOM elements of `event.el` (for example `event.el.content`) or the application-side style management.

## Listen for field modifications

Use the `formFieldModified` event of `FormManager` to detect when the runtime properties of a form field are modified. The listener receives a [`FormFieldModifiedEvent`]({{ site.api }}interface/formfieldmodifiedevent.html) object which contains the form uid and the new [`FormField`]({{ site.api }}interface/formfield.html) snapshot of the modified field.

```typescript
Dynamsoft.DDV.formManager.on("formFieldModified", (event) => {
  console.log("Field modified in form:", event.formUid);
  console.log("New field data:", event.newFieldProps);
});
```

## A complete example

The following example opens a document in an `EditViewer`, fills in the field "Name", checks the field "Agree", navigates to the field "Signature" and listens for widget clicks.

```typescript
// Assume that editViewer is an existing instance of EditViewer and a document is currently open.
const docUid = editViewer.currentDocument.uid;

// 1. Get the fields of the document.
const fields = Dynamsoft.DDV.formManager.getFields(docUid);
const fieldMap = new Map(fields.map(field => [field.uid, field]));

// 2. Fill in the fields by their names.
fieldMap.forEach((field, fieldUid) => {
  if (field.name === "Name") {
    Dynamsoft.DDV.formManager.setFieldProps(fieldUid, { value: "John" });
  }
  if (field.name === "Agree") {
    Dynamsoft.DDV.formManager.setFieldProps(fieldUid, { value: true });
  }
});

// 3. Navigate to the field to sign.
const signatureField = [...fieldMap.values()].find(field => field.name === "Signature");
if (signatureField) {
  editViewer.goToField(signatureField.uid);
}

// 4. Listen for widget clicks.
editViewer.on("widgetClicked", event => {
  console.log("Field uid:", event.fieldUid);
  console.log("Widget style:", event.style);
});
```
